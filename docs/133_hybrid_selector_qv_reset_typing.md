## 2. Selector-only event: finite observer/readout jump

Suppose the physical library is continuous through an event and only the active
readout changes from `E_-` to `E_+`.  Then

\[

\]

This is a finite readout/reset jump.  It is not a Brownian increment and does not
create an atom in the **continuous** bracket `[Y]^c`.

\[
\boxed{

\sum_{\tau\le T}\Delta Y_\tau\Delta Y_\tau^T.}

\[
\boxed{
\Delta[Y]_\tau=\Delta Y_\tau\Delta Y_\tau^T}

## 3. The jump square is only the quadratic face of pair revaluation

Write

\[

\[
\boxed{

\[
\boxed{

\[

\qquad
Y_+=E_+A\boldsymbol\chi_-,
\]

\[
\boxed{

\]

There are two exact algebraic decompositions,

\[
\begin{aligned}

&=(E_+-E_-)\boldsymbol\chi_-
