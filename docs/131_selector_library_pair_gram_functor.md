## 1. A genuine selector switch is not universal physical transport

Let a finite Kelvin candidate library have `N` physical residual fibers of dimension
`d` and write

\[
X=(r_1,\ldots,r_N)\in\bigoplus_{j=1}^N\mathbb R^d.
\]

The active germ `g` is read by the block extraction

\[
\boxed{r_g=E_gX.}
\]

Take `g\ne h`.  A universal old-selected-to-new-selected transport would require a
matrix `T` with

\[
\boxed{E_h=TE_g.}
\]

This is impossible.  Choose any nonzero library vector supported only in the `h`
block.  Then it lies in `ker E_g` but not in `ker E_h`.  Equivalently,

\[
\ker E_g\not\subseteq\ker E_h.
\]

By the finite-dimensional factorization criterion,

\[
B=TA\quad\Longleftrightarrow\quad\ker A\subseteq\ker B,
\]

no such `T` exists.

Hence

\[
\boxed{
\text{genuine selector switch}
\ne
\text{universal physical transport of the old selected residual}.}
\]

\[

\[

\[
\boxed{

+E_g\mathbb P\,\Delta E^T

\]

The old diagonal block does not determine these terms.  Indeed, take two
deterministic two-germ library states

\[
E_h\mathbb P_1E_h^T
=b_1b_1^T
\ne
b_2b_2^T
=E_h\mathbb P_2E_h^T.

universal compositional state across genuine switches.  Absent an extra admissible
