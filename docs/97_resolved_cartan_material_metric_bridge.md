## 1. Exact divergence-free adjoint split

Let `V` be a smooth real divergence-free resolved field on the periodic box (or a decaying field on `R^3`) and let `P` be Leray projection.  Put

\[
A_V=\nabla V=S_V+\Omega_V,
\qquad S_V^T=S_V,
\quad \Omega_V^T=-\Omega_V.
\]

For divergence-free vector fields define the actual resolved linearized Navier--Stokes operator

\[
\mathcal L_V f
=\mathbb P\big[(V\cdot\nabla)f+A_Vf\big]
=\mathbb P\big[(V\cdot\nabla)f+(f\cdot\nabla)V\big].
\]

Because `div V=0`, transport is skew-adjoint in `L^2`; because Leray is self-adjoint and can be dropped against divergence-free test fields,

\[
\mathcal L_V^*
=\mathbb P\big[-V\cdot\nabla+A_V^T\big].
\]

Hence

\[
\boxed{
\mathcal L_V=\mathcal K_V+\mathcal S_V,
\qquad
\mathcal K_V=\mathbb P(V\cdot\nabla+\Omega_V),
\qquad
\mathcal S_V=\mathbb P(S_V\,\cdot),
}
\]

with

\[
\boxed{
\mathcal K_V^*=-\mathcal K_V,
\qquad
\mathcal S_V^*=\mathcal S_V.
}
\]

This is the literal operator behind the `K/S` split used in Wang's resolved-interface and current resolved-contact branch.
