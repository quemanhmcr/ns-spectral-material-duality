# Support sufficiency, quadratic sufficiency, and cubic interaction sufficiency are different levels

Status: **Exact hierarchy and universal no-go for nontrivial phase-blind reduction.**

The kernel-selector and cubic-resolution theorems leave a structural question: can a reduced ancestry state be sufficient for physical event readout without being the full physical Kelvin state?

The answer depends on **which observable class must survive reduction**.  Hard support, second-order banks, and signed cubic interaction are genuinely different levels.

---

## 1. Support sufficiency

For a hard physical set `A`, the reduced kernel is support-sufficient exactly when

\[
\boxed{
R\chi_A\in\{0,1\},
}
\]

or equivalently

\[
\boxed{
R\chi_A(1-R\chi_A)=0.
}
\]

This only says that each reduced ancestry label lies entirely on one side of that physical cut.

It says nothing about hidden physical variation **inside** the selected side.

---

## 2. Support purity does not imply phase sufficiency

Take any non-Dirac conditional kernel supported entirely inside one physical selected set `A`.  Then

\[
\chi_A=1
\quad\kappa_y\text{-a.s.},
\]

so selector variance is zero exactly.

Inside that selected set use the even-parity hidden-state construction from the cubic-resolution theorem.  All reduced states remain physically selected, but

\[
\Delta_3^{res}
=R\mathcal T(\Phi_0,\Phi_1,\Phi_2)
-\mathcal T(R\Phi_0,R\Phi_1,R\Phi_2)
\ne0.
\]

Hence

\[
\boxed{
\text{hard support descent}
\not\Rightarrow
\text{cubic phase descent}.
}
\]

**Classification: COUNTEREXAMPLE/NO-GO.**

This matters for first-bad restart semantics: even a perfectly physical hard support label may still hide interaction orientation/phase among full current-shape states inside that support.

---

## 3. Quadratic sufficiency does not imply phase sufficiency

The even- and odd-parity kernels can have identical

- conditional means;
- one-leg quadratic moments;
- pair sign correlations and corresponding second-order cross data;

while their same-state cubics have opposite sign.

Therefore even exact knowledge of the relevant second-order bank does not make the reduced state interaction-sufficient.

\[
\boxed{
\text{second-order sufficiency}
\not\Rightarrow
\text{signed cubic sufficiency}.
}
\]

**Classification: COUNTEREXAMPLE/NO-GO.**

---

## 4. Universal cubic sufficiency forces a Dirac kernel

Assume the full physical state space is standard Borel.  Suppose a conditional kernel `kappa_y` satisfies, for **every** bounded measurable complex-vector triple,

\[
\boxed{
R\mathcal T(\Phi_0,\Phi_1,\Phi_2)
=\mathcal T(R\Phi_0,R\Phi_1,R\Phi_2).
}
\]

Choose a fixed oriented real basis `e_1,e_2,e_3` and set

\[
\Phi_0=f e_1,
\qquad
\Phi_1=g e_2,
\qquad
\Phi_2=h e_3.
\]

Then the hypothesis contains the scalar factorization law

\[
R(\overline f g h)
=\overline{Rf}\,(Rg)(Rh)
\]

for every bounded measurable `f,g,h`.

Set `h=1` and `g=f`.  One obtains

\[
\boxed{
R|f|^2=|Rf|^2
}
\]

for every bounded measurable `f`.  In particular, for every measurable set `A`, taking `f=chi_A` gives

\[
R\chi_A(1-R\chi_A)=0.
\]

Thus `kappa_y(A)` is `0` or `1` for every measurable set.  On a standard Borel space this means the probability measure is concentrated at one point:

\[
\boxed{
\kappa_y=\delta_{Y(y)}.
}
\]

Conversely a Dirac kernel obviously has exact cubic factorization.

Therefore

\[
\boxed{
\text{universal cubic sufficiency}
\Longleftrightarrow
\text{Dirac conditional kernel}
}
\]

on the physical standard-Borel state class.

**Classification: EXACT NECESSARY-AND-SUFFICIENT NO-GO THEOREM.**

---

## 5. The useful nontrivial possibility is interaction-sufficiency for a restricted physical algebra

The theorem does **not** say every reduced ancestry description is useless.  It says a nontrivial reduction cannot preserve arbitrary cubic observables for free.

A physically useful reduced state may still be sufficient for a restricted event algebra `A_phys` generated by the actual Navier--Stokes/Kelvin observables used in the theorem.  The exact condition is not a norm bound.  It is conditional factorization on that observable class, or equivalently explicit carriage of the corresponding resolution objects.

Thus there are two legitimate routes:

1. enlarge the state until the selected physical interaction observables are conditionally deterministic/sufficient; or
2. keep the reduced state and transport the exact `Delta_3^res`, selector correlation, and generator/source resolution faces.

A third route—discard hidden state but pretend covariance alone recovered phase—is ruled out.

**Classification: RIGOROUS STRUCTURAL CONSEQUENCE.**

## 6. Cross-bridge interpretation without merging architectures

The Wang event architecture keeps a smooth full field and applies the hard physical projector only at the actual event, so the event cubic is read from retained field information rather than inferred from quadratic carrier energy.

The Kelvin reduced-state problem is different, but the exact lesson is compatible: a reduced carrier must be judged by the event observables it preserves.  Support sufficiency and energy/covariance sufficiency are weaker than cubic interaction sufficiency.

This is not an architectural identification between the two programmes.  It is an exact information-content theorem about the physical observable being read.
