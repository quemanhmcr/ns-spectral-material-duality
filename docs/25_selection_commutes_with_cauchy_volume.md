# Physical event selection commutes with common Cauchy top-volume cancellation

Status: **Exact weighted same-replica identity.**

The Kelvin frontier still lacks the literal programme-specific first-bad
badness/resolve predicate.  This note does not invent one.  Instead it asks a
structural question that is already answerable: once a physical event weight has
been legitimately defined on the full hidden state, can that selection itself make
common incompressible Cauchy deformation become a phase owner?

The answer is no.

---

## 1. Arbitrary same-state event weights preserve the pathwise cancellation

Let `chi` be any real scalar measurable event/localization weight on the same hidden
physical state as `D,w_0,w_1,w_2`.  It may depend on anchor, deformation, terminal
fields, packet geometry, or any already-defined physical event data.  Since

\[
\mathcal T(Dw_0,Dw_1,Dw_2)
=\mathcal T(w_0,w_1,w_2)
\]

pathwise, multiplication by `chi` gives

\[
\boxed{
\mathbb E\big[\chi\,\mathcal T(Dw_0,Dw_1,Dw_2)\big]
=
\mathbb E\big[\chi\,\mathcal T(w_0,w_1,w_2)\big].
}
\]

**Classification: EXACT WEIGHTED CAUCHY / MATERIAL 3-FORM IDENTITY.**

For a hard event `chi=1_A`, this says selection changes which hidden states are
sampled, but it does not turn common `SL(3)` deformation into signed cubic work.

## 2. Normalized selected law has the same theorem

If

\[
\alpha=\mathbb E\chi>0,
\qquad
\mathbb E_\chi[F]=\frac{\mathbb E[\chi F]}{\alpha},
\]

then under the selected conditional law

\[
\boxed{
\mathbb E_\chi\mathcal T(Dw_0,Dw_1,Dw_2)
=
\mathbb E_\chi\mathcal T(w_0,w_1,w_2).
}
\]

All identities from the full Cauchy payoff factorization repeat with selected
moments

\[
\bar D_\chi=\mathbb E_\chi D,
\qquad
\bar w_{i,\chi}=\mathbb E_\chi w_i,
\qquad
r_{i,\chi}=\mathbb E_\chi[(D-\bar D_\chi)(w_i-\bar w_{i,\chi})].
\]

Thus event selection changes the conditional distribution and hence the resolution
terms, but **not the pathwise common-deformation cancellation**.

**Classification: EXACT CONDITIONAL REWEIGHTING CONSEQUENCE.**

\[
\text{selected metric alignment}

## 4. Where selected phase can actually change

Selection can still alter phase because reweighting changes

\[
\Delta_{w,\chi}
\quad\text{and}\quad
\mathcal C_{D-w,\chi},
\]

and because localized Navier--Stokes roles carry their own interface, forcing,

interaction distribution.

What selection cannot do is convert a common real pathwise `SL(3)` deformation into
an additional phase source merely by choosing a subset of replicas.

**Classification: COUNTEREXAMPLE/NO-GO against metric-selection phase charging.**
